## Advanced GPU Commands

**What this is:** Extra `SituationCmd*` functions for **low-level GPU control** — memory barriers, texture copies, mid-pass clears, explicit blend/depth state, indirect draws, and RenderDoc markers. They sit below the convenience helpers (`DrawQuad`, `DrawMesh`, `DrawTexture`) documented in [Graphics](graphics.md) and [2D Drawing](drawing_2d.md).

**What "renderer bolster" means:** Internal dev name for the project that added these commands. It is **not** a separate library or module you install — just extra entries in the same command buffer you already use.

**Full signature catalog:** Every `SituationCmd*` with OpenGL/Vulkan notes lives in **[situation_command_reference.md](../situation_command_reference.md)**. **Shipped vs deferred overview:** **[RENDERER_COMMAND_STACK.md](../RENDERER_COMMAND_STACK.md)**. This guide explains **when and why**, not a duplicate API dump.

### How Situation rendering is layered

```
  High level (most apps stop here)
    SituationCmdDrawQuad / DrawTexture / DrawTextEx / DrawMesh
           │
  Core path (custom VBOs, your shaders)
    BeginRenderPass → BindPipeline → BindVertexBuffer → DrawIndexed
           │
  Advanced (this guide)
    Barriers, CopyTexture, PushRasterState, DrawIndirect, mid-pass Clear, …
```

All layers record into the **same** command buffer:

```c
SituationAcquireFrameCommandBuffer();
SituationCommandBuffer cmd = SituationGetMainCommandBuffer();
/* … record commands … */
SituationEndFrame();   /* GPU executes here (OpenGL replays; Vulkan submits) */
```

Rules that apply everywhere:
- Record between `AcquireFrameCommandBuffer` and `EndFrame`.
- Most draws must be inside `SituationCmdBeginRenderPass` … `SituationCmdEndRenderPass`.
- **Transfers and barriers** usually happen **outside** a render pass (between passes or after compute).

### Problem → command map

Use this table to find the right tool. Signatures are in the [command reference](../situation_command_reference.md).

| Problem | Commands |
|---------|----------|
| Compute wrote a buffer; draw shader must read it | `SituationCmdPipelineBarrier` or `SituationCmdPipelineBarrierEx` |
| Compute wrote a texture; fragment shader samples it | Barrier + layout transition via `SituationCmdTextureBarrier` |
| Copy one GPU texture to another (same size) | `SituationCmdTextureBarrier` → `SituationCmdCopyTexture` → barrier back |
| Scale or filter-copy between textures | `SituationCmdBlitTexture` (with barriers) |
| Upload raw RGBA rows from a buffer to a texture | `SituationCmdCopyBufferToTexture` |
| Read texture pixels into a buffer (readback) | `SituationCmdCopyTextureToBuffer` |
| Copy region of one buffer to another | `SituationCmdCopyBufferEx` |
| Clear depth mid-pass (e.g. two depth layers in one pass) | `SituationCmdClearDepth` / `SituationCmdClear` |
| Clear at pass start | Prefer `SituationRenderPassInfo` load op `SIT_LOAD_OP_CLEAR` — no extra command |
| Draw UI over 3D without breaking depth/blend | `SituationCmdPushRasterState` → change blend/depth → draw → `PopRasterState` |
| Wireframe debug overlay | `SituationCmdSetPolygonMode(SIT_POLYGON_LINE)` inside push/pop |
| Shadow map acne (depth fighting) | `SituationCmdSetDepthBias` |
| 16-bit index buffer | `SituationCmdBindIndexBufferEx` (legacy `BindIndexBuffer` is UINT32 only) |
| Draw count generated by compute shader | `SituationCmdDrawIndirect` / `DrawIndexedIndirect` |
| Group count generated by compute | `SituationCmdDispatchIndirect` |
| Legacy transfer/blit strictness (opt-in fallbacks) | `SituationCmdSetRendererBehavior` / `PushRendererBehavior` / `PopRendererBehavior` |
| Label passes in RenderDoc / Nsight | `SituationCmdBeginDebugGroup` / `EndDebugGroup` |
| Split viewport or multi-scissor | `SituationCmdSetViewportIndexed` / `SetScissorIndexed` |

### Workflow 1 — Compute then draw

From `examples/other/compute_shader_image_processing.c` — invert image in compute, then use result in graphics:

```c
/* 1. Dispatch compute (can be outside render pass) */
SituationCmdBindComputePipeline(cmd, invert_pipeline);
SituationCmdBindComputeTexture(cmd, 0, storage_tex);
SituationCmdDispatch(cmd, groups_x, groups_y, 1);

/* 2. Barrier: compute write → vertex/fragment read */
SituationCmdPipelineBarrier(cmd,
    SITUATION_BARRIER_COMPUTE_SHADER_WRITE,
    SITUATION_BARRIER_VERTEX_SHADER_READ);

/* 3. Normal render pass using the texture */
SituationCmdBeginRenderPass(cmd, &pass);
SituationCmdDrawTexture(cmd, storage_tex, src, dst, origin, 0.0f, tint);
SituationCmdEndRenderPass(cmd);
```

If you skip the barrier, you may read stale GPU data (especially on Vulkan). See [Compute](compute.md) for pipeline setup.

### Workflow 2 — Copy texture between render targets

From `examples/demon_hunt/demon_hunt.c` — copy Virtual Display output to a feedback texture for bloom ( **outside** render pass):

```c
SituationCmdEndRenderPass(cmd);   /* transfers require pass to be closed */

SituationTextureBarrierDesc to_dst = {0};
to_dst.old_layout = SITUATION_TEXTURE_LAYOUT_SHADER_READ;
to_dst.new_layout = SITUATION_TEXTURE_LAYOUT_TRANSFER_DST;
SituationCmdTextureBarrier(cmd, feedback_tex, &to_dst);

SituationTextureCopyRegion region = {0};
region.src_rect = (SitRectangle){0, 0, w, h};
region.dst_x = 0;
region.dst_y = 0;
SituationCmdCopyTexture(cmd, vd_tex, feedback_tex, &region);

SituationTextureBarrierDesc to_read = {0};
to_read.old_layout = SITUATION_TEXTURE_LAYOUT_TRANSFER_DST;
to_read.new_layout = SITUATION_TEXTURE_LAYOUT_SHADER_READ;
SituationCmdTextureBarrier(cmd, feedback_tex, &to_read);

SituationCmdBeginRenderPass(cmd, &next_pass);
/* sample feedback_tex in shader … */
```

**Contract:** Situation does **not** insert hidden layout transitions for `CopyTexture` / `BlitTexture`. You own the barrier bookends.

### Workflow 3 — Temporary raster state (UI over world)

When 3D used depth testing and you draw a transparent HUD on top without polluting global state:

```c
SituationCmdPushRasterState(cmd, /*scope_id=*/1);

SituationCmdSetDepthTest(cmd, false, SIT_DEPTH_COMPARE_ALWAYS);
SituationCmdSetDepthWrite(cmd, false);
SituationCmdSetBlendEnable(cmd, true);
SituationCmdSetBlendFuncSeparate(cmd,
    SIT_BLEND_SRC_ALPHA, SIT_BLEND_ONE_MINUS_SRC_ALPHA,
    SIT_BLEND_ONE, SIT_BLEND_ONE_MINUS_SRC_ALPHA);

draw_hud(cmd);

SituationCmdPopRasterState(cmd, 1);   /* restores previous blend/depth/cull/etc. */
```

Stack depth: **256** levels (`SITUATION_MAX_RASTER_STACK_DEPTH`). `scope_id` is for your debug labels — push and pop must match.

Basic 2D (`DrawQuad`, `DrawTexture`) sets sensible defaults internally; you only need this when mixing custom 3D passes with overlays.

### Workflow 3b — Renderer behavior policy (opt-in convenience)

**Default:** every axis is strict. If you record no policy commands, transfer and blit behavior is unchanged from the strict cookbook path.

**When to use:** porting legacy examples that relied on implicit backend leniency, or reducing boilerplate barriers on trusted transfer paths — **not** for production defaults.

```c
SituationRendererBehaviorPolicy policy = SituationRendererBehaviorPolicyDefault();
policy.blit_filter = SIT_BLIT_FILTER_DOWNGRADE_NEAREST;
policy.transfer_usage = SIT_TRANSFER_USAGE_COMPATIBLE_FALLBACK;
policy.texture_layout = SIT_TEXTURE_LAYOUT_ASSISTED;
policy.validation = SIT_RENDERER_VALIDATION_WARN; /* log fallbacks; COMPAT is equivalent in v2.4 */

SituationCmdSetRendererBehavior(cmd, &policy);
/* copy/blit may now use assisted layout + narrow usage/filter fallbacks */
```

Stack semantics mirror raster state: **`PushRendererBehavior` / `PopRendererBehavior`**, max depth **32**, reset at frame begin. VD and internal compositor paths **ignore** user policy.

| Axis | Strict (default) | Opt-in |
|------|------------------|--------|
| `transfer_usage` | Missing `TRANSFER_SRC` → error | `COMPATIBLE_FALLBACK` for sampled RGBA8 read-only sources |
| `texture_layout` | You own every `TextureBarrier` | `ASSISTED` inserts transfer layout transitions from per-texture hints |
| `blit_filter` | Linear without sampled usage → error | `DOWNGRADE_NEAREST` executes nearest + optional warning |
| `validation` | Errors only | `WARN` / `COMPAT` emit `renderer behavior:` log lines when a fallback runs |

**Logging:** fallback warnings use `SituationLog(SIT_LOG_WARNING, …)`. They are suppressed when `validation` is `STRICT`, and also filtered by **`SituationSetTraceLogLevel`** — set the minimum level to `SIT_LOG_WARNING` or lower (e.g. `SIT_LOG_INFO`) to see them. Use `SituationSetLogCallback` to capture in tests or tools.

**Cookbook + harness:** **[RENDERER_BARRIER_COOKBOOK.md](../misc/RENDERER_BARRIER_COOKBOOK.md)** — `tests/harness/test_transfer.c` labels `transfer.behavior_*`.

### Workflow 4 — Debug capture groups

Wrap passes so GPU debuggers show meaningful names:

```c
SituationCmdBeginDebugGroup(cmd, "Shadow pass", (ColorRGBA){255, 128, 0, 255});
/* … shadow draws … */
SituationCmdEndDebugGroup(cmd);

SituationCmdBeginDebugGroup(cmd, "Main lighting", (ColorRGBA){0, 200, 255, 255});
/* … */
SituationCmdEndDebugGroup(cmd);
```

Visible in RenderDoc, Nsight, and similar tools when capturing a frame.

### Workflow 5 — Indirect / GPU-driven draw

For draw calls whose parameters live in a GPU buffer (filled by compute or CPU):

```c
/* Buffer holds SituationDrawIndirectCommand records */
SituationCmdBindPipeline(cmd, mesh_shader);
SituationCmdBindVertexBuffer(cmd, 0, vbo, 0, stride);
SituationCmdDrawIndirect(cmd, indirect_buffer, /*offset=*/0);
```

Indexed variant: bind index buffer first, then `SituationCmdDrawIndexedIndirect`.

Requires: active render pass, bound pipeline, valid vertex (and index) buffers. Indirect buffer must stay valid until `EndFrame`.

### Raster state commands (reference)

All pair with `PushRasterState` / `PopRasterState` when changes are temporary.

| Command | Typical use |
|---------|-------------|
| `SetCullMode` | `SIT_CULL_BACK` for 3D; `SIT_CULL_NONE` for 2D |
| `SetFrontFace` | Fix inverted winding (CW vs CCW) |
| `SetDepthTest` / `SetDepthWrite` | 3D ordering vs overlay |
| `SetDepthBias` | Shadow maps, decals |
| `SetPolygonMode` | Wireframe debug (`SIT_POLYGON_LINE`) |
| `SetPrimitiveTopology` | Lines/points vs triangles |
| `SetBlendEnable` / `SetBlendFuncSeparate` | Transparency |
| `SetColorWriteMask` | MRT or selective channel writes |
| `SetStencilTest` | Stencil shadows, masking |
| `SetLineWidth` | Wide lines (platform limits apply) |
| `SetMultisampleState` | In-pass flags (sample shading, mask, alpha-to-coverage). **Records successfully**; **no visible effect** until VD MSAA attachments ship (VD-4b). See [MSAA](#msaa-unified-model-v244398) below. |

### Barriers — quick guide

**Simple case (compute ↔ graphics):** use the flag-based wrapper:

```c
SituationCmdPipelineBarrier(cmd, src_flags, dst_flags);
```

**Fine-grained case:** `SituationCmdPipelineBarrierEx`, `SituationCmdBufferBarrier`, `SituationCmdTextureBarrier` with explicit stage/access/layout descriptors.

**Texture layouts** (for copy/blit/sample handoff):

| Layout | Meaning |
|--------|---------|
| `SITUATION_TEXTURE_LAYOUT_SHADER_READ` | Fragment/compute sampling |
| `SITUATION_TEXTURE_LAYOUT_TRANSFER_SRC` | Source of copy/blit |
| `SITUATION_TEXTURE_LAYOUT_TRANSFER_DST` | Destination of copy/blit |
| `SITUATION_TEXTURE_LAYOUT_GENERAL` | Storage image / compute write |

Transition: `old_layout` → `new_layout` on `SituationCmdTextureBarrier` before the transfer or sample that needs the new layout.

### OpenGL vs Vulkan notes

| Topic | OpenGL | Vulkan |
|-------|--------|--------|
| Command recording | Soft buffer replayed at `EndFrame` | Recorded to `VkCommandBuffer`, submitted at `EndFrame` |
| `SetVertexAttribute` | Supported — configure interleaved layout | **Not supported** — vertex format fixed at pipeline creation |
| Barriers | Mapped to `glMemoryBarrier` / conservative sync | Explicit stage/access masks |
| Raster state | Replayed from soft buffer | Dynamic state + pipeline variants where needed |
| Indirect draw | `glDrawArraysIndirect` / MDI paths | `vkCmdDrawIndirect` |

Backend-neutral signatures are intentional — check return `SituationError` on new commands; legacy `void` wrappers (e.g. `SituationCmdDispatch`) still exist for compatibility.

### Not implemented / limitations

| Feature | Status |
|---------|--------|
| **MSAA attachment quality (`> 1` sample)** | **Not supported yet** — use **`SituationMultisampleQuality`** helpers + **`max_msaa_samples`** to plan; VD/RT **`msaa_samples > 1`** rejected until **VD-4b (v2.5 default)** |
| `SituationCmdSetMultisampleState` | **Plumbing only (v2.4.256)** — GL soft replay; VK shadow + push/pop. Meaningful draws need multisampled attachments (VD-4b) |
| macOS process-style platform gaps | N/A here; see platform docs |
| Depth/stencil texture copy | Copy/blit commands target **color 2D RGBA8** textures today |
| Nested render passes | Not supported — end pass before starting another |

For maintainer-facing roadmap detail, see [`doc/plan/renderer_bolster_plan.md`](../plan/renderer_bolster_plan.md) (internal planning doc — not required reading for app developers).

### Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| Black or stale texture after compute | Missing barrier | Insert `PipelineBarrier` between dispatch and draw |
| `CopyTexture` fails or garbage output | Missing layout barrier | Transition SRC/DST layouts before/after copy |
| UI draws wrong after 3D pass | Raster state leak | Wrap UI in `PushRasterState` / `PopRasterState` |
| `PopRasterState` error | Stack underflow / mismatched `scope_id` | Every pop matches a push with same id |
| Indirect draw does nothing | No pipeline/buffer bound, or buffer not ready | Bind pipeline + VBO; barrier after compute fill |
| Works on GL, fails on VK | Vertex attrib on VK | Use pipeline-time layout; don't call `SetVertexAttribute` |
| `SetMultisampleState` fails | MSAA attachments not created | **`> 1` samples not supported yet**; cmd is valid but no-op on single-sample targets until VD-4b |

### MSAA unified model (v2.4.398+)

**One feature, two layers** — not three parallel APIs:

| Layer | API | v2.4.398 |
|-------|-----|----------|
| **Attachment quality** | **`SituationMultisampleQuality`** on VD/RT (today: map from **`desc.msaa_samples`**) | Types + VD storage; **`> 1` rejected** |
| **In-pass raster flags** | **`SituationMultisampleState`** + **`SituationCmdSetMultisampleState`** | Cmd records; no visible MSAA until layer 1 lands |

```c
SituationMultisampleQuality q = SituationMultisampleQualityClamp(
    SITUATION_MULTISAMPLE_4X, caps.max_msaa_samples);
int samples = SituationMultisampleQualitySampleCount(q);  /* 4, or lower if clamped */
```

**Window hint:** **`SITUATION_FLAG_MSAA_4X_HINT`** (init-only GLFW hint) will fold into the same enum at main-window MSAA (v2.5). See **[core — Graphics caps](core.md#situationmultisamplequality-v244398)** and **[virtual display — MSAA](virtual_display.md#msaa-attachment-quality-v244398)**.

For maintainer roadmap: **`doc/plan/renderer_bolster_plan.md`** § MSAA / multisample, **VD-4b Phase 0 @ v2.4.398**.

### API quick index

Grouped by job — see [command reference](../situation_command_reference.md) for full signatures.

**Synchronization:** `PipelineBarrier`, `PipelineBarrierEx`, `BufferBarrier`, `TextureBarrier`

**Clears:** `Clear`, `ClearColor`, `ClearDepth`, `ClearDepthStencil`, `ClearStencil`

**Transfer:** `CopyBufferEx`, `CopyTexture`, `BlitTexture`, `CopyBufferToTexture`, `CopyTextureToBuffer`

**Indirect:** `DrawIndirect`, `DrawIndexedIndirect`, `DispatchEx`, `DispatchIndirect`

**Raster:** `PushRasterState`, `PopRasterState`, `SetCullMode`, `SetFrontFace`, `SetDepthTest`, `SetDepthWrite`, `SetDepthBias`, `SetPolygonMode`, `SetLineWidth`, `SetPrimitiveTopology`, `SetBlendEnable`, `SetBlendFuncSeparate`, `SetColorWriteMask`, `SetStencilTest`, `SetMultisampleState`

**Behavior policy (Phase 14):** `SituationRendererBehaviorPolicyDefault`, `SetRendererBehavior`, `PushRendererBehavior`, `PopRendererBehavior`

**Viewport/scissor:** `SetViewportIndexed`, `SetScissorIndexed`

**Binding extras:** `BindIndexBufferEx`, `BindSampledTexture`, `BindDescriptorSetDynamic`, `SetPushConstantData`, `SetVertexAttribute` (GL only)

**Debug:** `BeginDebugGroup`, `EndDebugGroup`

**Other:** `SituationGetComputeCommandBuffer` (Vulkan compute recording — OpenGL uses main buffer)
